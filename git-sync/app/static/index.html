Mit GitHub verbinden

Git Sync koppelt deine Home-Assistant-Konfiguration an ein GitHub-Repository. Erstelle einen Personal Access Token (klassisch mit repo-Scope, oder fine-grained mit Contents- und Pull-Request-Schreibrechten) und füge ihn hier ein.
Personal Access Token
Schutz aktiv: secrets.yaml, .storage/ (Zugangsdaten & Token) und Datenbanken werden niemals übertragen. Der Token bleibt lokal in dieser App gespeichert.

Repository & Branch

Repository
oder
Main-Branch (Quelle der Wahrheit)
Wird automatisch auf deine Instanz übernommen.
Sync-Branch
Hier sammelt Git Sync deine lokalen Änderungen.
So arbeitet Git Sync Änderungen auf dem Main-Branch werden automatisch übernommen. Lokale Änderungen sammeln sich als Commits in einem offenen Pull Request auf dem Sync-Branch. Nur wenn du diesen PR mergst — hier oder auf GitHub — verändert sich der Main-Branch.
